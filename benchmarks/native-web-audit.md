# Native/Web capability audit — 2026-11-03

Baseline: published **0.1.0-rc.10**, commit `9e4d8c868aa1d5aa912c0826738fce40b48507da`.
The [machine-readable matrix](capability-matrix.json) accounts for 133 runtime exports (124 in RC.10 and nine local framework exports) across every package subpath, 60 Web runtime methods, and both keyframe property sets. `npm run parity:check` resolves actual TypeScript symbols and fails on unreviewed additions/removals, missing rows, missing evidence paths or untracked partial/pending work. Install the pinned native build tools with `npm ci --prefix benchmarks/native-app` first; their TypeScript compiler API is independent of the root build compiler.

`published` records availability, not complete semantic equivalence. `partial` identifies a changed contract or missing equivalent, `platform-specific` identifies native targets without a DOM counterpart, and `pending` identifies missing browser functionality. Type-only declarations, nested options, actual hardware behavior and visual correctness are not established by counting exports.

RC.10 includes the merged Web batches in #358, #365, #372 and #379: gradients/loading/text/reveal; particles/blur/shapes/images; keyboard/sheets/navigation/physics/symbols; gravity/haptics/sensors/glass/interactive return/keyed gallery. They must not remain labelled unpublished in current status summaries.
