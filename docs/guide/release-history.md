# Release history

## 0.1.0-rc.12.1: Portable composition and preferences {#release-candidate}

RC.12.1 adds [retained Web resources and Vue shape ownership, behavior coordination, gradient text, 2D rigs, shared helpers and effective reduced-motion observation](./portable-composition). Browser vector adapters share acquisition and native-compatible units; magnetic-field input explicitly reports unavailable. Install matching packages and rebuild native apps. Web APIs remain experimental.

Physical browser sensor delivery and accuracy remain pending in #385. Acceptance uses simulators/emulators and labeled injected browser readings. Publication makes no new performance or blocked-JavaScript playback claim.

## 0.1.0-rc.11.1: Native resource lifetime and composition {#rc-11-1}

RC.11.1 adds [retained resources and Vue drawing ownership, behavior priorities, articulated 2D parts, gradient text and named timeline effects](./native-composition). These native APIs include interruption, reduced motion and lifecycle controls for their documented use cases.

[Install RC.11.1](./install), keep the optional native package at the matching version and rebuild native apps. Latency and process-memory investigations remain technical debt (#405, #406); this release does not claim new performance gains or playback through blocked application JavaScript.

## 0.1.0-rc.11: Web refinement and native playback {#rc-11}

RC.11 refines [mobile keyboard handling](./web-platforms), [element-relative scroll ranges](./web-support) and surface-conflict diagnostics. Native additions include optional framework adapters, [device inputs](./device-sensors), [spring/scroll-driven shaders, liquid masks and silent local iOS video textures](./image-effects). [Android playback](./android-performance) retains less settled animation data; the audit exporter moves report work to a worker. The [physical-device study](./performance-study) records CPU, memory and presentation tradeoffs without changing application defaults.

Web APIs remain experimental. The website already uses the Web runtime for its sculpture, scroll response and playground; the native shader/video changes do not automatically apply to the DOM. [Install RC.11](./install), match the optional native package version and rebuild native apps. [Versioned changelog](https://github.com/rafaelaugustos/jolt/blob/v0.1.0-rc.11/CHANGELOG.md).

## 0.1.0-rc.4: native composition, resume and sheets {#rc-4}

RC.4 plays [endless layers with no common period](/guide/layers) on native composers instead of rebuilding four-second windows, so 64-view compositions go from hundreds of milliseconds per boundary to none on the measured phones. It continues [Android shapes, gradients and blur](/guide/shapes) from the paused time on resume, places the [bottom sheet](/guide/bottom-sheet) by the host's safe-area insets, and offers only the handle actions a stop can take.

The [preview](/guide/demo) has **74 examples in four languages**. [Install RC.4](/guide/install) and rebuild the native app. Read the [release notes](https://github.com/rafaelaugustos/jolt/releases/tag/v0.1.0-rc.4) and the [remaining physical-device acceptance](/guide/not-there-yet) before stable.
